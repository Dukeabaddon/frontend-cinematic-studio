# Visual Philosophy

## Core thesis

Modern AI UI is clean, smooth, and **emotionally empty**. This skill reverses that: handcrafted, atmospheric, cinematic, tactile, editorially paced.

Target feeling:

- Anime collector artbooks, fantasy manuscripts, Kinfolk editorials
- Studio Ghibli mood boards, luxury visual novels, exhibition sites

**Not:** startup SaaS, crypto dashboards, Framer clones, blur spam, dashboard-first thinking.

## Emotional hierarchy

1. **Focal point** — one primary anchor per viewport (figure, headline, artifact)
2. **Pacing** — wide hero → dense metadata → immersive full-bleed → quiet footer
3. **Breathing room** — asymmetry and negative space are intentional
4. **Rhythm** — vary density; identical `gap-6` grids everywhere = machine slop

## Why generic UI fails

| Failure | Emotional cost |
|---------|----------------|
| Default gradients | Feels template, not directed |
| Flat z-stack | No depth, no immersion |
| Motion everywhere | Nervous, cheap |
| Fake premium chrome | Trust breaks |
| Centered symmetry only | No editorial tension |

## Tactile premium

- Material layering (parchment, grain, mist)
- Physical transitions (dissolve zones, not opacity-only fades)
- Restrained motion with hierarchy
- Imperfections that feel human (slight rotation on photo clusters ±2–4°)
